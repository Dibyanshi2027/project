# Startup Investment Analysis using Shark Tank India Data

## Project Overview
This project analyzes startup investment trends using Shark Tank India data. The goal of the project is to identify funding patterns, investor activity, startup valuation trends, and industry-wise investment distribution.
The project was completed using Python for data analysis and Tableau for dashboard visualization.

## Objectives
* Analyze startup funding patterns
* Identify top-funded industries
* Study investor participation trends
* Visualize startup valuation and equity relationships
* Build an interactive dashboard for business insights
  
## Tools and Technologies Used
* Python
* Pandas
* Matplotlib
* Seaborn
* Tableau Public
* Jupyter Notebook
  
## Dataset
The dataset contains startup investment information from Shark Tank India, including:
* Startup Name
* Industry
* Investment Amount
* Equity Taken
* Valuation Requested
* Investor Details
* Season Information
  
## Project Workflow
1. Imported dataset into Jupyter Notebook
2. Cleaned missing and duplicate data
3. Performed exploratory data analysis (EDA)
4. Created visualizations using Matplotlib and Seaborn
5. Exported cleaned dataset
6. Built interactive Tableau dashboard
7. Generated insights and conclusions
   
## Key Insights
* Technology and food startups attracted major investments.
* Some investors participated more actively than others.
* Higher investment amounts were often associated with higher equity percentages.
* Startup valuation and investment patterns varied across industries.
  
## Project Deliverables
* Python Notebook (`startup_analysis.ipynb`)
* Tableau Dashboard (`Startup_Investment_Analysis.twb`)
* Cleaned Dataset (`cleaned_shark_tank.csv`)
* Final Report (`final_report.pdf`)
